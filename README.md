# 豆包去水印助手

这是一个基于 Android WebView 构建的豆包辅助应用项目，主要用于在豆包网页中提供“去水印/无水印下载”相关能力。仓库中包含 APK 反编译/解包后的工程结构，包括 AndroidManifest、资源文件、DEX、库文件和配置资产等。

## 项目概述

- 应用名称：豆包去水印助手
- 包名：com.doudou.tu
- 目标站点：https://www.doubao.com/chat
- 版本信息：3.6
- 主要能力：图像下载、视频下载、账号切换、UA 切换、页面增强等

从项目配置可见，该应用会以内置浏览器方式打开豆包，并注入一系列页面脚本和增强逻辑，用于处理图像/视频的无水印下载功能。

## 目录说明

- `AndroidManifest.xml`：Android 应用清单
- `assets/`：应用静态资源与配置文件
- `res/`：Android 资源目录
- `lib/`：原生/第三方库
- `classes*.dex`：字节码文件
- `META-INF/`：签名和元数据
- `org/`、`okhttp3/`：对应依赖库内容
- `app_config.json`：应用配置入口，包含站点地址、应用名称、功能开关等

## 主要功能

- 图片去水印下载
- 视频无水印下载
- 多账号切换
- 手机端/桌面端 UA 切换
- 页面增强与悬浮工具入口
- WebView 集成的浏览器启动方式
- 新增多平台通用脚本支持：即梦 / Dola / 小云雀 / 可灵

## 已接入平台

- 豆包：原有增强脚本与下载入口
- 即梦：增加通用媒体识别与下载入口
- Dola：增加通用媒体识别与下载入口
- 小云雀：增加通用媒体识别与下载入口
- 可灵：增加通用媒体识别与下载入口

> 说明：本项目基于当前 WebView 方案做统一脚本接入，适用于多个 AI 生成/内容平台的通用资源检测与下载增强。具体是否能稳定提取无水印资源，仍受目标站点接口、CDN、签名和前端结构变化影响。

## 使用方式

1. 使用 Android Studio 或相关工具打开该工程。
2. 确认依赖和资源文件完整后，编译或安装 APK。
3. 启动应用后进入豆包页面。
4. 在页面中使用悬浮功能入口进行图片/视频下载等操作。

> 说明：此仓库更偏向 APK 解包后的工程结构，不一定包含完整的原始源码树；如需进一步开发，建议结合 `apktool`、`jadx` 等工具继续反编译与还原源码。
